МАРШРУТ B — ГОТОВАЯ ПРОГРАММА

1. Распакуйте архив целиком. Не перемещайте картинки отдельно от приложения.
2. Запустите START_WINDOWS.bat. Нужен Python 3 только для локального веб-сервера; Tesseract и pip НЕ НУЖНЫ.
3. Если браузер не открылся автоматически: http://127.0.0.1:8080
4. В программе есть маршрут по 5–30 вопросов, продолжение каждой темы, ошибки, закладки, пробный экзамен и экспорт прогресса.
5. Встроены все 2332 вопроса и 1126 изображений из присланного архива. Для подготовки к категории B отобраны 1762 вопроса из 45 тем. Исключены дополнительные темы для мотоциклов, грузовых автомобилей, автобусов и троллейбусов, несмотря на ошибочную метку B в старой базе.
6. Прогресс хранится в браузере по адресу/порту. Не очищайте данные сайта и используйте экспорт прогресса для резервной копии.
7. Для запуска на телефоне через интернет START_HTTPS.bat требует отдельно установленную утилиту cloudflared. Это необязательно для работы на Windows.
