PDR B - READY TO USE / Windows and mobile

1. Unzip the entire ZIP, keeping the images and data folders.
2. Double-click START_WINDOWS.bat. Python 3 is required for the local web server (no Python packages, no OCR).
3. Open http://127.0.0.1:8080 if your browser did not open automatically.
4. Choose "All topics", "Study route", "Review mistakes", or "Exam".
5. Keep your browser storage for your progress. Back it up via Settings -> Export progress.
6. START_HTTPS.bat is an optional Cloudflare tunnel for browser use on another device; requires cloudflared already in PATH. Do not publish this personal server unless you understand who may access its URL.

Bundled dataset: 2332 original questions, 1126 unique images; category B study: common sections and B/B1 sections 44-47, 1762 questions in 45 sections. The archive originated from an earlier PDF parser (2026-08); it has NOT been freshly re-scraped or independently checked against every current official answer. Some answers were recognized using OCR. The one low-confidence question s35_q051 is visibly flagged and excluded from sample exams.
Official source: https://hsc.gov.ua/index/poslugi/vidacha-posvidchennya-vodiya/pitannya-ta-ispit-z-pdr/

All BAT launchers contain only ASCII commands/messages.
